## 📖 About the Project

This portfolio was created as a **student assignment** to demonstrate proficiency in front-end web development. It highlights the academic journey and project experience of **Surya K**, a B.Tech student at Reva University, Bangalore.

The design focuses on readability, modern UI/UX trends (dark mode, gradient accents, subtle animations), and full responsiveness across all devices.

## ✨ Features

- **Fully Responsive** – Adapts seamlessly to desktop, tablet, and mobile screens.
- **Dark & Modern UI** – Professional color palette with glowing accent colors.
- **Interactive Components** – Hover effects, mobile hamburger menu, and smooth scrolling.
- **Contact Form** – Client-side validation with a simulated submission alert.
- **Visual Skill Bars** – Dots representation for proficiency levels (Proficient / Intermediate).
- **Dynamic Animations** – Smooth fade-in effects triggered by scrolling.

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Custom properties (variables), Flexbox, Grid, animations, and media queries
- **JavaScript (Vanilla)** – DOM manipulation, event handling, Intersection Observer API
- **Font Awesome** – Icon library for badges, skills, and social links
- **Google Fonts (Inter)** – Clean, modern typography
